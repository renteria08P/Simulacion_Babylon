IDEA GENERAL DEL PROYECTO

El proyecto consiste en una aplicación interactiva desarrollada con:

- Babylon.js
- Vite
- Android Studio

Permitirá visualizar y manipular un sistema gravitacional en 3D y en Realidad Aumentada (RA).

El usuario podrá interactuar directamente con planetas y cuerpos celestes para comprender cómo funcionan las leyes de la mecánica clásica y la gravedad.
